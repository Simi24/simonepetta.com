C.1 Inizializzazione e Firme degli Strumenti

Il Listato C.1 fornisce un estratto architetturalmente rilevante dell’implementazione del server Model Context Protocol (MCP) sviluppato per il framework Service-Forge. Il codice evidenzia esclusivamente l’inizializzazione del servizio, le istruzioni di base fornite al modello linguistico e la registrazione degli strumenti operativi (tools) tramite tipizzazione forte, la quale agisce da schema di validazione statica per i payload JSON. Per questioni di leggibilità, la logica procedurale di basso livello è stata omessa.

C.2 Esempio template Jinja

Il Listato C.2 mostra un esempio dei template generativi basati sul motore Jinja2, in particolare si tratta del template usato per generare il file docker-compose.yaml in tutti i microservizi. La sintassi illustra la separazione netta tra la logica di iniezione dinamica delle variabili e la struttura statica del codice sorgente, garantendo la standardizzazione formale dei microservizi prodotti dal framework aziendale.

services:
  {{ service_name }}:
    build:
      context: .
      target: dev
    platform: linux/arm64
    restart: on-failure
    environment:
      {% if app_name -%}
      APP_NAME: {{ app_name }}
      {%- else -%}
      APP_NAME: {{ service_name }}
      {%- endif %}
      {%- for key, value in environment.items() %}
      {{ key }}: {{ value }}
      {%- endfor %}
      {%- block aws_services_block %}{%- endblock %}
      {%- if use_localstack %}
      AWS_ENDPOINT_URL: http://localstack:4566
      AWS_ACCESS_KEY_ID: test
      AWS_SECRET_ACCESS_KEY: test
      AWS_DEFAULT_REGION: {{ aws_region }}
      AWS_LAMBDA_FUNCTION_TIMEOUT: {{ lambda_timeout }}
      AWS_LAMBDA_FUNCTION_MEMORY_SIZE: {{ lambda_memory_size }}
      {%- endif %}
    volumes:
      - ./app:/var/task
      - ~/.aws:/root/.aws:ro
    ports:
      - {{ service_port }}:8080
      - 5678:5678
    {% if profile == 'service' -%}
    command:
      sh -c "echo 'Please run the debugger to proceed (F5)' && python -Xfrozen_modules=off -m debugpy --listen 0.0.0.0:5678 --wait-for-client -m uvicorn main:app --host 0.0.0.0 --port 8080 --reload --log-level debug"
    {%- endif  %}

{% if use_localstack %}
  localstack:
      image: localstack/localstack
      ports:
          - "127.0.0.1:4566:4566"
          - "127.0.0.1:4510-4559:4510-4559"
      env_file:
          - .env.template
          - .env
      environment:
          DEBUG: ${DEBUG:-0}
      volumes:
          - "${LOCALSTACK_VOLUME_DIR:-./localstack_volume}:/var/lib/localstack"
          - "/var/run/docker.sock:/var/run/docker.sock:ro"
          - "./init-aws.sh:/etc/localstack/init/ready.d/init-aws.sh:ro"
{%- endif%}
